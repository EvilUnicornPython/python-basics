# Шаблон доски

На интервью некогда искать, как в Miro рисуется цилиндр. Доску собираешь заранее и копируешь на каждый мок / собес.
Подойдёт Miro, Excalidraw, draw.io — что разрешат. Заранее узнай у рекрутёра, в чём будет созвон и рисование, и протестируй.

## Фреймы (слева направо)
1. **Задача** — сюда вставляешь условие
2. **Требования** — две колонки: функциональные / нефункциональные
3. **Допущения** — цифры и решения, которые ты предложил сам
4. **Оценка нагрузки** — RPS, объём, read/write
5. **C1** — пустой фрейм с кубиком «Наша система» в центре
6. **C2** — пустой фрейм
7. **За скобками** — то, что видим, но сегодня не рассматриваем
8. **Вопросы** — что всплыло по ходу, вернуться в конце

## Библиотека кубиков
Сбоку от фреймов, чтобы копировать:
- юзер / роль (человечек)
- веб-клиент (SPA), мобильное приложение
- балансировщик / API gateway
- веб-сервис / API
- воркер, планировщик (cron)
- очередь, лог событий (stream)
- SQL БД + реплика (цилиндры)
- KV / кэш, NoSQL, поисковый индекс
- объектное хранилище, CDN
- внешняя система (другим цветом): чужое API, биржа, мессенджер, платёжка
- мониторинг / алерты

## Стикеры (по цветам)
- жёлтый — требование
- зелёный — допущение
- красный / 🔥 — горлышко при росте
- серый — за скобками

## Стрелки
Две заготовки: сплошная — синхронный вызов, пунктирная — асинхронно (через очередь / событие). Подпись — только если без неё непонятно.

## Тренировка
- нарисуй на шаблоне C1 и C2 своего текущего рабочего проекта
- засеки время: условие любой задачи из [`napkin.md`](napkin.md) → требования + C1 за 10 минут
- повторяй, пока рисование не перестанет отвлекать от речи
